# Car Black Box

## Project Overview

Developed a Car Black Box system using Embedded C and the PIC16F877A microcontroller to record vehicle events, including timestamps and speed information. The system stores event records in EEPROM for later retrieval.

## Technologies Used

- Embedded C
- PIC16F877A Microcontroller
- Timers and Interrupts
- EEPROMd
- CLCD and Keypad
- PICSimLab

## Features

- Records vehicle events with timestamps.
- Stores vehicle speed and event details.
- Saves event records in EEPROM.
- Uses timers and interrupts for event handling.

## Tools Used

- MPLAB X IDE
- XC8 Compiler
- PICSimLab
